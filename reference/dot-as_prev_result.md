# build a `ph_prev_result` object

build a `ph_prev_result` object

## Usage

``` r
.as_prev_result(data, meta)
```

## Arguments

- data:

  tibble/data.frame with results

- meta:

  named list with accounting info (m_by_rank, pools, pairs, etc.)

## Value

`data` with extra attributes and class `ph_prev_result`
